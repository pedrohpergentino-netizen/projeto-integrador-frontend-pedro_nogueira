# MedSurgical Equipamentos

A MedSurgical Equipamentos é uma empresa fictícia especializada na venda de equipamentos e instrumentos cirúrgicos.
O projeto apresenta um catálogo de produtos destinados a ambientes hospitalares e clínicas.
O objetivo é facilitar a consulta aos equipamentos disponíveis e apresentar informações sobre seus produtos.
O projeto será desenvolvido utilizando HTML, CSS e JavaScript ao longo da disciplina.
